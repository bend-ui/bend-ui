# `@bend-ui/base-ui`

Bend UI package adapter over **Base UI** (`@base-ui/react`). This is the v0 focus adapter.

- **Upstream library**: Base UI — https://base-ui.com/react/overview/quick-start
- **Pinned version**: see `@base-ui/react` in `package.json` (source of truth).

## Where to look

- **How to build components here** (structure, `createStyleContext` / `withRecipe` pattern,
  adding a component, missing-component checks): the `component-libraries` skill.
- **What's implemented and how complete it is** (product intent, progress, quality
  coverage, verified-against-upstream marker): `docs/component-catalog.md`.

This file is intentionally thin — it does not duplicate the how-to or component lists.
