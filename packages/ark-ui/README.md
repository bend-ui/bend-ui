# @bend-ui/ark-ui

> **Experimental and frozen.** This Bend UI adapter over [Ark UI](https://ark-ui.com)
> is kept building and tested, but it gets no new components or investment and is not a
> support target for new work. Base UI (`@bend-ui/base-ui`) is the focus.

## Running unit tests

Run `pnpm nx test ark-ui` to execute the unit tests via [Vitest](https://vitest.dev/).
