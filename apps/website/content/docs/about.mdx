Bend UI helps teams build a design system without tying their visual design to one headless component library.

## Why recipes

Styles live in Panda CSS recipes, not in component code. A package adapter applies the recipes to one headless library's components, so changing a token, a theme or a recipe restyles every component that uses it.

## Why Base UI first

Base UI is the first supported adapter and the focus of the initial release. That release aims for a small, complete set of Base UI components, a design preset and these docs.

## How these docs are built

This site is a Next.js app built on the headless Fumadocs packages. Its layout, sidebar and navigation use `@bend-ui/base-ui` components and the Bend UI design preset, so the docs also exercise the Base UI adapter.

## Project status

Bend UI is a proof of concept. The packages are not published to npm, and the API can change without a deprecation period.
