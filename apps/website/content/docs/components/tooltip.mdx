# Tooltip

Tooltips display a visual label on hover or keyboard focus. Match the label to the trigger’s accessible name; put supplemental information inline or in a Popover so it is accessible to screen readers. See the [working workspace](/docs/components/overlays-navigation).

```tsx
<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger>Help</Tooltip.Trigger>
    <Tooltip.Portal>
      <Tooltip.Positioner sideOffset={8}>
        <Tooltip.Popup>Help</Tooltip.Popup>
      </Tooltip.Positioner>
    </Tooltip.Portal>
  </Tooltip.Root>
</Tooltip.Provider>
```

The `tooltip` recipe styles trigger, popup and arrow. Use `Tooltip.Provider` to coordinate delays. `Tooltip` now aliases its prop-driven Root; the former fixed formatting-toolbar demo is removed. Popup surface context and consumer overrides survive the portal.
