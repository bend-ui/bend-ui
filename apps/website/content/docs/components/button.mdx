# Button

The Button component is used to trigger actions and events. It supports various styles, sizes, and states.

## Import

```tsx
import { Button } from '@particles/react';
```

## Basic Usage

```tsx
import { Button } from '@particles/react';

function Example() {
  return <Button>Click me</Button>;
}
```

## Variants

The Button component supports different visual styles:

```tsx
import { Button, Stack } from '@particles/react';

function VariantsExample() {
  return (
    <Stack direction="row" gap="4">
      <Button variant="solid">Solid</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
      <Button variant="link">Link</Button>
    </Stack>
  );
}
```

### Variant Types

- **solid** (default): Filled background with solid color
- **outline**: Transparent background with border
- **ghost**: Transparent background, shows on hover
- **link**: Styled as a text link

## States

### Disabled

```tsx

  return (

```

### Loading

Show a loading state:

```tsx

  return (
    <Stack direction="row" gap="4">
      <Button isLoading>Loading</Button>

```

## Accessibility

The Button component follows accessibility best practices:

- Uses semantic `<button>` element
- Supports keyboard navigation (Enter/Space)
- Includes proper ARIA attributes
- Indicates disabled and loading states
- Maintains focus management

### Accessible Example

```tsx
import { Button } from '@particles/react';

function AccessibleExample() {
  return (
    <Button
      aria-label="Delete item"
      onClick={() => console.log('Delete clicked')}
    >
      Delete
    </Button>
  );
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'solid' \| 'outline' \| 'ghost' \| 'link'` | `'solid'` | Visual style variant |
| `colorScheme` | `string` | `'blue'` | Color scheme to apply |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'` | Button size |
| `disabled` | `boolean` | `false` | Disable the button |
| `isLoading` | `boolean` | `false` | Show loading state |
| `loadingText` | `string` | - | Text to show when loading |
| `leftIcon` | `ReactElement` | - | Icon to show on left |
| `rightIcon` | `ReactElement` | - | Icon to show on right |
| `width` | `string \| number` | - | Button width |
| `onClick` | `() => void` | - | Click handler |

## Examples

### Submit Button

```tsx
import { Button } from '@particles/react';

function SubmitExample() {
  const [isLoading, setIsLoading] = React.useState(false);

  const handleSubmit = async () => {
    setIsLoading(true);
    await submitForm();
    setIsLoading(false);
  };

  return (
    <Button
      type="submit"
      colorScheme="blue"
      isLoading={isLoading}
      loadingText="Submitting..."
      onClick={handleSubmit}
    >
      Submit
    </Button>
  );
}
```

### Delete Button

```tsx
import { Button } from '@particles/react';
import { TrashIcon } from '@particles/icons';

function DeleteExample() {
  return (
    <Button
      variant="outline"
      colorScheme="red"
      leftIcon={<TrashIcon />}
      onClick={() => console.log('Delete')}
    >
      Delete
    </Button>
  );
}
```

## Best Practices

1. **Use appropriate variants**: Solid for primary actions, outline/ghost for secondary
2. **Consistent sizing**: Use the same sizes throughout your app
3. **Clear labels**: Button text should clearly indicate the action
4. **Loading states**: Show feedback during async operations
5. **Disabled states**: Clearly indicate when actions are unavailable
