# Components Overview

The Base UI package adapter combines accessible upstream behavior with Bend UI recipes. Import interactive components from `@bend-ui/base-ui`; import layout elements and styling helpers from the styled system generated in your application.

## Import components and layouts

```tsx
import { Button, Heading, Input, Text } from '@bend-ui/base-ui';
import { Box, Stack } from 'styled-system/jsx';
```

`@bend-ui/base-ui` exposes a named-import catalog. It does not require a separate foundation package or per-component subpath imports.

## Compose a card

```tsx
import { Button, Heading, Text } from '@bend-ui/base-ui';
import { Box, Stack } from 'styled-system/jsx';

export function FeatureCard() {
  return (
    <Box padding="6" borderWidth="1px" borderRadius="lg">
      <Stack gap="4">
        <Heading as="h2">Foundation-free composition</Heading>
        <Text as="p">Behavior and layout come from separate, focused modules.</Text>
        <Button variant="primary">Learn more</Button>
      </Stack>
    </Box>
  );
}
```

## Build a form field

Compound components follow Base UI's composition model:

```tsx
import { Button, Field } from '@bend-ui/base-ui';
import { Stack } from 'styled-system/jsx';

export function SearchForm() {
  return (
    <Stack as="form" gap="4">
      <Field.Root>
        <Field.Label>Search</Field.Label>
        <Field.Control placeholder="Search components" />
      </Field.Root>
      <Button type="submit" variant="primary">
        Search
      </Button>
    </Stack>
  );
}
```

## Choose the right import

| Need | Import from |
| --- | --- |
| Interactive component or compound part | `@bend-ui/base-ui` |
| Layout element such as `Box`, `Stack`, `Flex`, or `Grid` | `styled-system/jsx` |
| A class for custom styling | `styled-system/css` |
| A layout class rather than a JSX element | `styled-system/patterns` |

## Accessibility

Adapter components preserve the semantics and keyboard behavior of their Base UI primitives. Supply accessible names and application-specific ARIA relationships where the component's content does not provide them.
