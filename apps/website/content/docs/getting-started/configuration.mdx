# Configuration

Bend UI separates component behavior from application styling:

- `@bend-ui/base-ui` provides the Base UI package adapter.
- `@bend-ui/preset` provides Bend UI tokens, recipes, themes, and conditions.
- Panda generates application-owned styling helpers in `styled-system`.

## Basic Panda configuration

```typescript
import { defineConfig } from '@pandacss/dev';
import { createBendPreset } from '@bend-ui/preset';

export default defineConfig({
  preflight: true,
  presets: [createBendPreset()],
  include: [
    './src/**/*.{js,jsx,ts,tsx}',
    './app/**/*.{js,jsx,ts,tsx}',
    './node_modules/@bend-ui/base-ui/**/*.{js,jsx,ts,tsx}',
  ],
  outdir: 'styled-system',
  jsxFramework: 'react',
});
```

## Extend design tokens

Pass Panda configuration alongside the design preset when your product needs additional tokens:

```typescript
import { defineConfig } from '@pandacss/dev';
import { createBendPreset } from '@bend-ui/preset';

export default defineConfig({
  presets: [createBendPreset()],
  theme: {
    extend: {
      tokens: {
        colors: {
          brand: {
            500: { value: '#3b82f6' },
            700: { value: '#1d4ed8' },
          },
        },
      },
    },
  },
});
```

## Configure TypeScript aliases

If your build does not resolve the generated directory automatically, add a path alias:

```json
{
  "compilerOptions": {
    "paths": {
      "styled-system/*": ["./styled-system/*"]
    }
  },
  "include": ["src", "styled-system"]
}
```

## Use generated helpers

Generated JSX elements accept Panda style props. The `css` helper creates classes for native or adapter components.

```tsx
import { Button } from '@bend-ui/base-ui';
import { css } from 'styled-system/css';
import { Box, Stack } from 'styled-system/jsx';

export function Example() {
  return (
    <Box padding="6" borderWidth="1px" borderRadius="lg">
      <Stack gap="4">
        <p>Configuration is working.</p>
        <Button className={css({ alignSelf: 'start' })}>Continue</Button>
      </Stack>
    </Box>
  );
}
```

Regenerate the styled system after changing the Panda configuration.
