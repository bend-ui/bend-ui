Bend UI separates component behavior from application styling:

- `@bend-ui/base-ui` provides the Base UI package adapter and ships Bend UI's Panda design system: tokens, recipes, themes, and conditions.
- Panda generates application-owned styling helpers in `styled-system`.

## Basic Panda configuration

Use the same configuration as [Installation](/docs/getting-started/installation):

```typescript
import { defineConfig } from '@pandacss/dev';

export default defineConfig({
  designSystem: '@bend-ui/base-ui',
  include: ['./src/**/*.{js,jsx,ts,tsx}'],
  outdir: 'styled-system',
  jsxFramework: 'react',
  preflight: true,
});
```

`designSystem` loads Bend UI's preset and recipes from the package. Do not add a `node_modules` glob or repeat Bend UI's preset.

## Extend design tokens

Add your own tokens under `theme.extend`:

```typescript
import { defineConfig } from '@pandacss/dev';

export default defineConfig({
  designSystem: '@bend-ui/base-ui',
  include: ['./src/**/*.{js,jsx,ts,tsx}'],
  outdir: 'styled-system',
  jsxFramework: 'react',
  preflight: true,
  theme: {
    extend: {
      tokens: {
        colors: {
          brand: {
            500: { value: '#3b82f6' },
            700: { value: '#1d4ed8' },
          },
        },
      },
    },
  },
});
```

## Configure TypeScript aliases

If your build does not resolve the generated directory automatically, add a path alias:

```json
{
  "compilerOptions": {
    "paths": {
      "styled-system/*": ["./styled-system/*"]
    }
  },
  "include": ["src", "styled-system"]
}
```

## Use generated helpers

Bend UI layout elements accept Panda style props. The generated `css` helper creates classes for native or adapter components.

```tsx
import { Box, Button, Stack } from '@bend-ui/base-ui';
import { css } from 'styled-system/css';

export function Example() {
  return (
    <Box padding="6" borderWidth="1px" borderRadius="lg">
      <Stack gap="4">
        <p>Configuration is working.</p>
        <Button className={css({ alignSelf: 'start' })}>Continue</Button>
      </Stack>
    </Box>
  );
}
```

Regenerate the styled system after changing the Panda configuration.
