# Installation

Install the Base UI package adapter, the Bend UI design preset, and Panda CSS. The adapter provides accessible components; Panda generates the layout and styling helpers used by your application.

## Prerequisites

- Node.js 18 or later
- React 19
- A project configured for Panda CSS

## 1. Install the packages

### pnpm

```bash
pnpm add @bend-ui/base-ui @bend-ui/preset
pnpm add -D @pandacss/dev
```

### npm

```bash
npm install @bend-ui/base-ui @bend-ui/preset
npm install --save-dev @pandacss/dev
```

### Yarn

```bash
yarn add @bend-ui/base-ui @bend-ui/preset
yarn add --dev @pandacss/dev
```

## 2. Configure Panda CSS

Create `panda.config.ts`:

```typescript
import { defineConfig } from '@pandacss/dev';
import { createBendPreset } from '@bend-ui/preset';

export default defineConfig({
  preflight: true,
  presets: [createBendPreset()],
  include: [
    './src/**/*.{js,jsx,ts,tsx}',
    './app/**/*.{js,jsx,ts,tsx}',
    './node_modules/@bend-ui/base-ui/**/*.{js,jsx,ts,tsx}',
  ],
  outdir: 'styled-system',
  jsxFramework: 'react',
});
```

## 3. Generate the styled system

Add Panda code generation to `package.json`:

```json
{
  "scripts": {
    "prepare": "panda codegen"
  }
}
```

Then generate the local `styled-system` directory:

```bash
pnpm prepare
```

## 4. Render a component

```tsx
import { Button } from '@bend-ui/base-ui';
import { Stack } from 'styled-system/jsx';

export function App() {
  return (
    <Stack gap="4">
      <h1>Welcome to Bend UI</h1>
      <Button variant="primary">Get started</Button>
    </Stack>
  );
}
```

Use `@bend-ui/base-ui` for interactive adapter components. Use your generated `styled-system/jsx`, `styled-system/css`, and `styled-system/patterns` modules for layout and custom styling.
