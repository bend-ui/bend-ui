Install the Base UI package adapter and Panda CSS. The adapter provides accessible components and ships Bend UI's Panda design system; Panda generates the layout and styling helpers used by your application.

## Release status

Bend UI packages are not published yet. They are at version `0.0.1` and are not on npm, so the install commands below will fail until a release ships. `@bend-ui/base-ui` also depends on `@bend-ui/core`, which is private. The repository checks this setup by installing packed tarballs in a separate app (`pnpm nx run panda-consumer:verify`).

## Prerequisites

- Node.js 24 or later
- React 19
- Panda CSS 2 (`@pandacss/dev` 2.2.0 or later)

## 1. Install the packages

### pnpm

```bash
pnpm add @bend-ui/base-ui
pnpm add -D @pandacss/dev
```

### npm

```bash
npm install @bend-ui/base-ui
npm install --save-dev @pandacss/dev
```

### Yarn

```bash
yarn add @bend-ui/base-ui
yarn add --dev @pandacss/dev
```

## 2. Configure Panda CSS

Create `panda.config.ts`:

```typescript
import { defineConfig } from '@pandacss/dev';

export default defineConfig({
  designSystem: '@bend-ui/base-ui',
  include: ['./src/**/*.{js,jsx,ts,tsx}'],
  outdir: 'styled-system',
  jsxFramework: 'react',
  preflight: true,
});
```

`designSystem` loads Bend UI's preset, recipes, and prebuilt extraction data from the installed package. Scan only your own source: do not add a `node_modules` glob or repeat Bend UI's preset. If your code lives outside `src`, add that folder to `include`.

## 3. Generate the styled system and CSS

Add Panda generation to `package.json`:

```json
{
  "scripts": {
    "prepare": "panda codegen && panda cssgen --outfile styled-system/styles.css"
  }
}
```

Then run it:

```bash
pnpm prepare
```

This writes the local `styled-system` directory and a `styled-system/styles.css` file. Run it again after you change your source or `panda.config.ts`.

## 4. Import the CSS

Import the generated CSS once from your application entry:

```tsx
import '../styled-system/styles.css';
```

## 5. Render a component

```tsx
import { Button, Stack } from '@bend-ui/base-ui';

export function App() {
  return (
    <Stack gap="4">
      <h1>Welcome to Bend UI</h1>
      <Button variant="primary">Get started</Button>
    </Stack>
  );
}
```

Use `@bend-ui/base-ui` for interactive adapter components and layout elements (`Box`, `Stack`, `Flex`, `Grid`, `styled`). Use your generated `styled-system/css` and `styled-system/patterns` modules for class-based styling.
