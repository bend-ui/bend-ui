Bend UI is a set of Panda CSS recipes and React package adapters that style headless component libraries. Base UI is the first supported library.

## How it works

Base UI provides component behavior: state, keyboard interaction, focus management and ARIA attributes. Bend UI provides the styling as Panda CSS recipes, so you can change how a component looks without rewriting its behavior.

The work is split across packages:

- `@bend-ui/preset-base` provides the shared foundation: component contracts (parts, slots and state selectors), conditions, patterns and base recipes.
- `@bend-ui/preset` adds the visual language: tokens, semantic tokens, recipes and themes.
- `@bend-ui/base-ui` wraps Base UI components and applies the recipes.

## Current status

- The packages are at version 0.0.1 and are not published to npm. The API can change.
- These docs cover only the Base UI adapter. Adapters for React Aria Components and Ark UI exist in the repository, but they are not documented and not ready to use. The Ark UI adapter is frozen as an experiment.
- Bend UI does not claim WCAG conformance. Accessible behavior comes from Base UI, and some recipe colors don't yet meet contrast requirements.
- Generating components into your own project and ejecting them for local ownership are planned, not built.
