# Quick Start

This tutorial builds a small sign-in card using adapter components for behavior and generated Panda elements for layout.

## Create the page

```tsx
import { Button, Field } from '@bend-ui/base-ui';
import { Box, Stack } from 'styled-system/jsx';

export function SignIn() {
  return (
    <Box maxWidth="md" marginX="auto" padding="8">
      <Stack gap="6">
        <Stack gap="2">
          <h1>Sign in</h1>
          <p>Use your work email to continue.</p>
        </Stack>

        <Field.Root>
          <Field.Label>Email</Field.Label>
          <Field.Control type="email" autoComplete="email" required />
          <Field.Error match="valueMissing">Enter your email address.</Field.Error>
        </Field.Root>

        <Button type="submit" variant="primary" isFull>
          Continue
        </Button>
      </Stack>
    </Box>
  );
}
```

`Field` and `Button` come from the Base UI package adapter, so their behavior follows the upstream primitives. `Box` and `Stack` come from the generated styled system, so the application owns their output and styling API.

## Add custom styling

Use `css` when you need a class instead of a generated JSX element:

```tsx
import { Button } from '@bend-ui/base-ui';
import { css } from 'styled-system/css';

export function QuietAction() {
  return (
    <Button className={css({ alignSelf: 'start' })} variant="tertiary">
      Skip for now
    </Button>
  );
}
```
