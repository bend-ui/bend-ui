This tutorial builds a small sign-in card using adapter components for behavior and Bend UI layout elements, both imported from `@bend-ui/base-ui`.

## Create the page

```tsx
import { Box, Button, Field, Stack } from '@bend-ui/base-ui';

export function SignIn() {
  return (
    <Box maxWidth="md" marginX="auto" padding="8">
      <Stack as="form" action="/sign-in" method="post" gap="6">
        <Stack gap="2">
          <h1>Sign in</h1>
          <p>Use your work email to continue.</p>
        </Stack>

        <Field.Root>
          <Field.Label>Email</Field.Label>
          <Field.Control name="email" type="email" autoComplete="email" required />
          <Field.Error match="valueMissing">Enter your email address.</Field.Error>
        </Field.Root>

        <Button type="submit" variant="primary" isFull>
          Continue
        </Button>
      </Stack>
    </Box>
  );
}
```

`Field` and `Button` come from the Base UI package adapter, so their behavior follows the upstream primitives. `Box` and `Stack` are Bend UI layout elements; their style props are typed against Bend UI's tokens. If you extend the tokens and want your own tokens typed in layout props, import the layout elements from your generated `styled-system/jsx` instead.

## Add custom styling

Use `css` when you need a class instead of a generated JSX element:

```tsx
import { Button } from '@bend-ui/base-ui';
import { css } from 'styled-system/css';

export function QuietAction() {
  return (
    <Button className={css({ alignSelf: 'start' })} variant="tertiary">
      Skip for now
    </Button>
  );
}
```
