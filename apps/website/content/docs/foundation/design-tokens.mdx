# Design Tokens

The Bend UI design preset provides tokens for color, spacing, typography, radii, shadows, and motion. Panda turns those tokens into typed values in your generated styled system.

## Use tokens through style props

```tsx
import { Box } from 'styled-system/jsx';

export function Card({ children }: { children: React.ReactNode }) {
  return (
    <Box
      padding="6"
      borderRadius="lg"
      borderWidth="1px"
      borderColor="stroke.weak"
      backgroundColor="fill.weak"
      boxShadow="sm"
    >
      {children}
    </Box>
  );
}
```

The prop values are resolved by Panda during generation. Your application code does not import a runtime token object from a React foundation package.

## Use tokens in a CSS class

```tsx
import { css } from 'styled-system/css';

export const notice = css({
  padding: '4',
  borderRadius: 'md',
  color: 'text',
  backgroundColor: 'fill.weak',
});
```

## Extend the token system

Extend the preset in `panda.config.ts` when a product needs additional design values:

```typescript
import { defineConfig } from '@pandacss/dev';
import { createBendPreset } from '@bend-ui/preset';

export default defineConfig({
  presets: [createBendPreset()],
  theme: {
    extend: {
      tokens: {
        spacing: {
          content: { value: '4.5rem' },
        },
      },
      semanticTokens: {
        colors: {
          accent: { value: '{colors.blue.500}' },
        },
      },
    },
  },
});
```

Run Panda code generation after changing tokens so the generated types and CSS stay in sync.

## Token categories

| Category | Typical use |
| --- | --- |
| Colors | Text, fills, strokes, and state feedback |
| Spacing | Gaps, padding, margins, and layout rhythm |
| Typography | Font family, size, weight, and line height |
| Radii | Control and surface shapes |
| Shadows | Surface elevation |
| Motion | Transition duration and easing |

Prefer semantic tokens in product UI. Use raw palette values when defining or extending the semantic layer, not throughout component code.

See [Theme Personalities](/docs/foundation/themes) for the canonical manifests and generated color specimens.
