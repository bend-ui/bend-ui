# Spacing

Use the generated styled-system elements for layout. Their spacing props resolve through the Bend UI token system.

## Add space inside a surface

```tsx
import { Box } from 'styled-system/jsx';

export function Panel({ children }: { children: React.ReactNode }) {
  return (
    <Box padding="6" borderWidth="1px" borderRadius="lg">
      {children}
    </Box>
  );
}
```

## Stack content vertically

```tsx
import { Button, Heading, Text } from '@bend-ui/base-ui';
import { Stack } from 'styled-system/jsx';

export function EmptyState() {
  return (
    <Stack gap="4" alignItems="start">
      <Heading as="h2">No projects yet</Heading>
      <Text as="p">Create a project to begin.</Text>
      <Button variant="primary">Create project</Button>
    </Stack>
  );
}
```

## Arrange actions horizontally

```tsx
import { Button } from '@bend-ui/base-ui';
import { Flex } from 'styled-system/jsx';

export function FormActions() {
  return (
    <Flex gap="3" justifyContent="end" flexWrap="wrap">
      <Button variant="secondary">Cancel</Button>
      <Button variant="primary">Save</Button>
    </Flex>
  );
}
```

## Constrain page content

```tsx
import { Container, Stack } from 'styled-system/jsx';

export function Page({ children }: { children: React.ReactNode }) {
  return (
    <Container maxWidth="7xl" paddingX="6" paddingY="8">
      <Stack gap="8">{children}</Stack>
    </Container>
  );
}
```

## Guidelines

- Use `gap` on layout containers instead of margins between their children.
- Use `Stack` for one-dimensional groups and `Flex` when alignment or wrapping matters.
- Use `Container` to constrain page width and `Box` for a styled semantic-neutral surface.
- Choose token values before introducing one-off literal measurements.
