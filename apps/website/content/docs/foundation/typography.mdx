# Typography

Typography is a critical part of any design system. Particles provides a comprehensive type system that ensures consistency and readability.

## Font Families

### Default Fonts

Particles uses system font stacks for optimal performance:

```tsx
import { Text } from '@particles/react';

// Body text (default)
<Text fontFamily="body">
  This is body text using the system font stack
</Text>

// Monospace for code
<Text fontFamily="mono">
  const example = 'monospace font';
</Text>
```

### Font Stack

```css
/* Body */
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto',
  'Oxygen', 'Ubuntu', 'Cantarell', 'Fira Sans', 'Droid Sans',
  'Helvetica Neue', sans-serif;

/* Monospace */
font-family: ui-monospace, SFMono-Regular, 'SF Mono', Menlo,
  Consolas, 'Liberation Mono', monospace;
```

## Font Sizes

### Scale

Particles uses a modular scale for font sizes:

```tsx
import { Text, Stack } from '@particles/react';

<Stack gap="4">
  <Text fontSize="xs">Extra small text (0.75rem / 12px)</Text>
  <Text fontSize="sm">Small text (0.875rem / 14px)</Text>
  <Text fontSize="md">Medium text (1rem / 16px)</Text>
  <Text fontSize="lg">Large text (1.125rem / 18px)</Text>
  <Text fontSize="xl">Extra large text (1.25rem / 20px)</Text>
  <Text fontSize="2xl">2XL text (1.5rem / 24px)</Text>
  <Text fontSize="3xl">3XL text (1.875rem / 30px)</Text>
  <Text fontSize="4xl">4XL text (2.25rem / 36px)</Text>
  <Text fontSize="5xl">5XL text (3rem / 48px)</Text>
</Stack>
```

### Usage Guidelines

- **Body text**: Use `md` (16px) for most content
- **Small text**: Use `sm` (14px) for secondary information
- **Headings**: Use `2xl` and above
- **Captions**: Use `xs` or `sm`

## Font Weights

```tsx
import { Text, Stack } from '@particles/react';

<Stack gap="2">
  <Text fontWeight="normal">Normal weight (400)</Text>
  <Text fontWeight="medium">Medium weight (500)</Text>
  <Text fontWeight="semibold">Semibold weight (600)</Text>
  <Text fontWeight="bold">Bold weight (700)</Text>
</Stack>
```

### Weight Guidelines

- **Normal (400)**: Body text
- **Medium (500)**: Emphasized text
- **Semibold (600)**: Subheadings, buttons
- **Bold (700)**: Headings, strong emphasis

## Line Heights

Line height affects readability and visual density:

```tsx
import { Text, Stack } from '@particles/react';

<Stack gap="4">
  <Text lineHeight="tight">
    Tight line height (1.25) - Good for headings
  </Text>
  <Text lineHeight="normal">
    Normal line height (1.5) - Good for body text
  </Text>
  <Text lineHeight="relaxed">
    Relaxed line height (1.75) - Good for long-form content
  </Text>
</Stack>
```

### Line Height Scale

- `tight`: 1.25
- `snug`: 1.375
- `normal`: 1.5
- `relaxed`: 1.75
- `loose`: 2

## Text Styles

### Predefined Styles

```tsx
import { css } from 'styled-system/css';

// Heading style
<h1 className={css({
  fontSize: '4xl',
  fontWeight: 'bold',
  lineHeight: 'tight',
  letterSpacing: 'tight',

  fontSize: 'md',
```

## Responsive Typography

Scale typography for different screen sizes:

```tsx
import { css } from 'styled-system/css';

<h1 className={css({
  fontSize: {
    base: '2xl',
    md: '3xl',
    lg: '4xl',
  },
})}>
  Responsive Heading
</h1>
```

## Accessibility

### Guidelines

1. **Minimum Size**: Don't use text smaller than 12px
2. **Contrast**: Ensure sufficient contrast (4.5:1 for normal text)
3. **Line Length**: Keep lines between 45-75 characters
4. **Hierarchy**: Use semantic HTML headings (h1-h6)

### Example with Good Contrast

```tsx
import { Box, Text } from '@particles/react';

<Box bg="gray.900" padding="8">
  <Text color="white" fontSize="lg">
    High contrast white text on dark background
  </Text>
</Box>
```


## Custom Fonts

To use custom fonts, add them in your app:

```typescript
// app/layout.tsx
import { Inter } from 'next/font/google';

const inter = Inter({ subsets: ['latin'] });

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body className={inter.className}>{children}</body>
    </html>
  );
}
```

Update your Panda config:

```typescript
export default defineConfig({
  theme: {
    extend: {
      tokens: {
        fonts: {
          body: { value: 'Inter, sans-serif' },
        },
      },
    },
  },
});
```
