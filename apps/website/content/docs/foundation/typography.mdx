# Typography

Use semantic HTML first. The Base UI adapter provides `Heading` and `Text` components that combine semantic elements with the Bend UI text recipe.

## Headings

Choose the HTML level with `as`:

```tsx
import { Heading } from '@bend-ui/base-ui';
import { Stack } from 'styled-system/jsx';

export function Headings() {
  return (
    <Stack gap="3">
      <Heading as="h1">Account settings</Heading>
      <Heading as="h2">Profile</Heading>
      <Heading as="h3">Contact details</Heading>
    </Stack>
  );
}
```

Keep heading levels in document order. Change visual emphasis with style or recipe props rather than skipping semantic levels.

## Body text

```tsx
import { Text } from '@bend-ui/base-ui';
import { Stack } from 'styled-system/jsx';

export function Description() {
  return (
    <Stack gap="2">
      <Text as="p">Changes are saved automatically.</Text>
      <Text as="p" color="text.weak">
        Last saved a minute ago.
      </Text>
    </Stack>
  );
}
```

`Text` renders a `span` by default. Set `as="p"` for a paragraph or choose another element that matches the content's meaning.

## Style native text

Use the generated `css` helper for semantic elements that do not need an adapter component:

```tsx
import { css } from 'styled-system/css';

export function KeyboardHint() {
  return (
    <p>
      Press <kbd className={css({ fontFamily: 'mono', fontSize: 'sm' })}>Esc</kbd> to close.
    </p>
  );
}
```

## Guidelines

- Select elements for meaning, then apply visual styles.
- Keep body text at a readable line length.
- Use semantic color tokens such as `text` and `text.weak`.
- Preserve the user's font-size preferences; avoid fixed pixel sizes for long-form text.
