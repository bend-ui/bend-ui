Bend UI styles headless React components with Panda CSS recipes. Base UI is the first supported library, and these docs cover the `@bend-ui/base-ui` package.

Bend UI is a work in progress. The packages are not published to npm yet, and the API can change.

## Start here

- [Introduction](/docs/getting-started/introduction): what Bend UI is and how its packages fit together.
- [Installation](/docs/getting-started/installation): add Bend UI to a Panda CSS project.
- [Components](/docs/components/overview): import and compose the Base UI components.
- [Design tokens](/docs/foundation/design-tokens): the tokens that recipes and themes are built on.
