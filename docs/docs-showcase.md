# Documentation site and studio showcase

The website uses Fumadocs Core and MDX for content and navigation, with Bend UI and Panda for its interface. The studio workspace at `/showcase` demonstrates an editable project list, filtering, form validation, Select and a contextual Dialog. All project data lives in React state for the lifetime of the page; refreshing discards it. It is an example, not an account or persistence service.

From the workspace root, install dependencies with `pnpm install`, then use `NX_DAEMON=false pnpm nx run website:serve` for development. Build with `NX_DAEMON=false pnpm nx run website:build` and run the production server with `NX_DAEMON=false pnpm nx run website:start`. A compatible Next.js host can serve the production build. The documentation search endpoint requires a server-capable Next.js deployment; static export has not been verified for this site. No deployment is performed by these commands.

The installation page documents package installation and Panda generation; the design-token and recipe-customization pages explain consumer configuration and the published variant boundary. Component pages describe composition, anatomy and keyboard behavior, including validation and focus. Consumers must verify custom colors and focus indicators in each supported mode and surface. The site does not certify the legacy default personality or all consumer overrides.
