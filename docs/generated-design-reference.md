# Generated design reference

BEN-47 adds a source-derived reference for Button, Select and representative Stratus color tokens. The site generator is a narrow build-time adapter: it reads the existing structural and design recipes, prototype component contracts, personality aliases and palette, then uses TypeScript to resolve a selected set of public `ButtonProps` and `SelectProps<string>` members. The type adapter reads the defining declarations of the same publicly exported types, avoiding a full barrel check on each development rebuild. The output is serializable data for the existing MDX site. It does not add a runtime package or compile source in the browser.

The reference names its limits: the prop list is selected rather than exhaustive, Select uses a concrete string value, and the color view covers Stratus primary values. Contract variants/defaults and anatomy/state slots are checked against recipe data and discrepancies are shown in the page; unavailable prop types and unresolved alias chains are reported rather than invented. Token aliases are followed through the personality source to their named palette values. The adapter deliberately reads defining package files so this comparison can detect drift. When BEN-51 changes the token contract, update the token-reading adapter and its tests against the merged source rather than preserving a duplicate token table.

Fumadocs Core and MDX supply the existing content processing and syntax highlighting. [Fumadocs' separate TypeScript integration](https://fumadocs.dev/docs/markdown/typescript) can generate compiler metadata, but is not installed; its documented auto table also requires a supplied presentation component. This implementation uses the workspace's existing TypeScript compiler and a small site-owned table, without adding `fumadocs-ui` or a second MDX pipeline.

Website preparation generates the data after Panda code generation. Its Nx inputs include the relevant package sources. Development uses webpack, watches those sources, and fingerprints extraction inputs so unchanged rebuilds skip regeneration. See the generated page for current data rather than treating this document as an API catalog.
